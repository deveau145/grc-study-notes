# 📘 GRC Study Notes

This repository contains my personal notes and templates from my journey into Governance, Risk, and Compliance (GRC) in cybersecurity. These notes are built from coursework (e.g. SimplyCyber GRC course, ECC cyberlaw/ethics), frameworks (NIST CSF, ISO 27001), and hands-on experience.

## 🔍 Topics Covered

- Risk Register Template (based on NIST CSF)
- Sample Acceptable Use Policy
- Incident Response Workflow (CIS Controls)
- Vendor Risk Assessment Template
- GRC Interview Prep Notes
- Policy Writing Best Practices

## 📎 Use Cases

These documents are meant to help me (and others) learn how to:
- Align cybersecurity practices with business goals
- Write and implement security policies
- Assess and manage organizational risk
- Prepare for GRC job interviews or certifications
